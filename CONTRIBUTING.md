# Contributing

Thanks for helping. Please read this first: it keeps the project legally clean.

## Licensing rules
- Contributions are accepted under **GPL-3.0-or-later**.
- Port only from the free [Elementor plugin](https://github.com/elementor/elementor) (GPLv3) or from sources whose licence you have checked.
- **Never** submit code derived from Elementor Pro or from any copy that bypasses its licence check.

## Setup
```bash
composer install
vendor/bin/phpunit
```
Widgets only implement `render()`; controls and style selectors come from `resources/schema` (generated by `tools/dump-schema`).
Original modules (Form, Loop Grid, Nav Menu) ship their own schema JSON in `resources/schema/widgets/`.

## Pull requests
- Add or update tests; `vendor/bin/phpunit` must pass.
- Keep user input going through the existing sanitizers (`Support\Html`, `StyleGenerator`).
- One topic per PR; describe what changed and how you checked it.
